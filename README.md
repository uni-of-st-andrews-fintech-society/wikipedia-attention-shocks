# wikipedia-attention-shocks

**University of St Andrews FinTech Society whitepaper project.**

Question: does a sudden spike in a company's Wikipedia pageviews (an "attention shock") predict its next-day stock return relative to other S&P 500 stocks, and can a small neural network use it to beat a linear benchmark after costs?

> Not investment advice. This is a research project.

```bash
pip install -r requirements.txt
cp .env.example .env   # add your own User-Agent email
```
